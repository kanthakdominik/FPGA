## Po co to jest

Verilog nie sprawdza typów — sam decyduje, na ilu bitach i czy ze znakiem policzyć wyrażenie, według reguł, które trzeba znać na pamięć. Błędy rozmiaru i znaku to najczęstsza przyczyna sytuacji „symulacja działa na małych liczbach, a sprzęt nie” i stały temat rozmów kwalifikacyjnych. W zamian Verilog ma zwięzłe operatory bitowe, redukcji, konkatenacji i replikacji, których VHDL długo nie miał.

## Intuicja

Wyrażenie w Verilogu liczone jest w dwóch krokach. Najpierw narzędzie ustala **szerokość** całego wyrażenia — największą spośród argumentów i **lewej strony przypisania** — i **znak** (ze znakiem tylko, gdy wszystkie argumenty są ze znakiem). Potem poszerza każdy argument do tej szerokości i dopiero liczy. Kto o tym pamięta, przewiduje wynik; kto nie, dostaje obcięte przeniesienia i liczby ujemne zamienione na ogromne dodatnie.

## Teoria

### Liczby

| Zapis | Znaczenie |
|-------|-----------|
| `8'b1010_0101` | 8 bitów, dwójkowo; `_` dla czytelności |
| `8'hA5`, `8'd165`, `8'o245` | szesnastkowo, dziesiętnie, ósemkowo |
| `4'sb1011` | 4 bity **ze znakiem** (−5) |
| `-8'sd5` | −5 na 8 bitach ze znakiem |
| `165` | bez rozmiaru: **32 bity ze znakiem** |
| `'hA5` | bez rozmiaru, bez znaku: 32 bity |
| `8'bx`, `4'bz` | wszystkie bity `x` / `z` |
| `'0`, `'1` (SV) | wypełnij całą szerokość zerami / jedynkami |

### Operatory

| Grupa | Operatory | Uwagi |
|-------|-----------|-------|
| arytmetyczne | `+ - * / % **` | `/` i `%` ze zmiennym dzielnikiem — kosztowne ([01.04](../01-logika-cyfrowa/01.04-uklady-arytmetyczne-sumatory-przeniesienia.md)) |
| bitowe | `~ & \| ^ ~^` | bit po bicie |
| logiczne | `! && \|\|` | wynik 1-bitowy; wektor ≠ 0 to prawda |
| redukcji | `&x  \|x  ^x  ~&x  ~\|x  ~^x` | jeden argument, wynik 1-bitowy: AND/OR/XOR wszystkich bitów |
| porównania | `== != < > <= >=`, `=== !==` | `===` tylko w symulacji |
| przesunięcia | `<< >>` (logiczne), `<<< >>>` (arytmetyczne) | `>>>` powiela bit znaku **tylko** dla wyrażeń ze znakiem |
| konkatenacja | `{a, b, 2'b01}` | szerokość = suma szerokości; każdy element musi mieć rozmiar |
| replikacja | `{4{a}}`, `{{8{x[7]}}, x}` | ostatni przykład: rozszerzenie znakiem z 8 do 16 bitów |
| warunkowy | `s ? a : b` | multiplekser |
| wycinki | `x[7:4]`, `x[i*8 +: 8]`, `x[i*8+7 -: 8]` | `+:` / `-:` — wycinek o stałej szerokości i zmiennym początku |

### Reguły rozmiaru

1. Argumenty „zależne od kontekstu” (arytmetyka, bitowe, `?:`) są poszerzane do szerokości największego argumentu **i lewej strony przypisania**.
2. Argumenty „samodzielne” mają własną szerokość: konkatenacja, wynik porównania i operatorów logicznych (1 bit), redukcja (1 bit), indeks i wycinek, argument replikacji.
3. Poszerzanie: zerami dla wyrażeń bez znaku, bitem znaku — dla ze znakiem.
4. Wynik przypisany do węższej zmiennej jest obcinany od góry — **bez błędu**.

Przykład z [01.04](../01-logika-cyfrowa/01.04-uklady-arytmetyczne-sumatory-przeniesienia.md): `{cout, s} = a + b;` — lewa strona ma W + 1 bitów, więc dodawanie odbywa się na W + 1 bitach i przeniesienie zostaje. `s = a + b;` gubi je. W ALU z [04.05](../04-vhdl/04.05-instrukcje-sekwencyjne-if-case-i-petle.md#kod-verilog) `{carry, y} = a + ~b + 1` liczy `~b` po poszerzeniu do W + 1 bitów — stąd konkatenacje `{1'b0, ~b}`.

### Reguły znaku

- Wyrażenie jest ze znakiem **tylko wtedy, gdy wszystkie** jego argumenty są ze znakiem. Jedna stała bez znaku (`8'hFF`) albo jeden wektor `[7:0]` i całe wyrażenie liczy się bez znaku.
- Wycinek (`x[7:0]`) i konkatenacja są **zawsze bez znaku**, nawet z sygnału `signed`.
- `$signed(x)`, `$unsigned(x)` zmieniają interpretację bez zmiany bitów.
- Liczby całkowite bez rozmiaru (`5`) są ze znakiem, z rozmiarem bez `s` (`8'd5`) — bez znaku.

```verilog
wire signed [7:0] a = -8'sd3;
wire        [7:0] u = 8'd4;
wire signed [8:0] y1 = a + u;            // bez znaku! a poszerzone zerami: 253 + 4 = 257, czyli −255 w 9 bitach ze znakiem
wire signed [8:0] y2 = a + $signed(u);   // ze znakiem: −3 + 4 = 1
wire signed [8:0] y3 = a + $signed({1'b0, u}); // poprawnie dla u ≥ 128: zero przed zmianą interpretacji
```

### Przykłady w kodzie tej lekcji

- [avg_signed.v](hdl/verilog/avg_signed.v) — `(a + b) >>> 1` na W + 1 bitach ze znakiem: średnia zaokrąglona w dół. Wszystkie argumenty `signed`, więc poszerzenie powiela bit znaku, a `>>>` jest arytmetyczne.
- [bit_tricks.v](hdl/verilog/bit_tricks.v) — sztuczki bitowe znane z rozmów:
  - `x & (x - 1)` zeruje najmłodszą jedynkę; wynik 0 (przy x ≠ 0) oznacza potęgę dwójki,
  - `x & -x` (czyli `x & (~x + 1)`) zostawia tylko najmłodszą jedynkę,
  - `^x` — parzystość, `&x` — „same jedynki”, `|x` — „cokolwiek”,
  - odwrócenie kolejności bitów pętlą `generate`.

## Kod: Verilog

```verilog
    // avg_signed.v
    wire signed [W:0] sum  = a + b;          // a, b: input wire signed [W-1:0]
    wire signed [W:0] half = sum >>> 1;
    assign y = half[W-1:0];

    // bit_tricks.v
    assign is_pow2  = (|x) && ((x & (x - 1'b1)) == {W{1'b0}});
    assign lowest   = x & (~x + 1'b1);
    assign parity   = ^x;
```

## Co powstaje po syntezie

Yosys (CI, W = 8): `avg_signed` — **22 LUT4**, sumator 9-bitowy bez dodatkowej logiki (przesunięcie to tylko wybór przewodów); `bit_tricks` — **21 LUT4**. `bit_tricks`: `rev` to same połączenia (0 LUT), parzystość i `&x` — drzewa LUT, `lowest` — łańcuch odejmowania z AND.

## Weryfikacja

- `tb_avg_signed` — wszystkie pary liczb 4-bitowych ze znakiem. Model w każdym języku liczy podłogę inaczej: Verilog z poprawką dla ujemnych nieparzystych (bo `/` zaokrągla do zera), VHDL przez `mod`, SV przez `$floor` na liczbach rzeczywistych.
- `tb_bit_tricks` — 256 wartości, model z pętli po bitach.

## Reguły i liczby do zapamiętania

| Reguła lub liczba | Kiedy obowiązuje |
|-------------------|------------------|
| Szerokość wyrażenia = max(argumenty, lewa strona przypisania) | arytmetyka, bitowe, `?:` |
| Ze znakiem tylko, gdy **wszystkie** argumenty są ze znakiem | każde wyrażenie |
| Wycinki i konkatenacje są zawsze bez znaku | Verilog, SV |
| Liczba bez rozmiaru = 32 bity ze znakiem | stałe |
| `>>>` jest arytmetyczne tylko dla wyrażeń ze znakiem | przesunięcia |
| `x & (x - 1)` zeruje najmłodszą jedynkę; `x & -x` ją izoluje | sztuczki bitowe |
| Rozszerzenie znakiem: `{{N{x[W-1]}}, x}` | poszerzanie ręczne |

## Typowe pułapki

- ⚠️ **Mieszanie `signed` i bez znaku** — całe wyrażenie bez znaku, liczby ujemne stają się duże.
- ⚠️ **Obcięcie przy przypisaniu** — bez błędu; Verilator zgłasza ostrzeżenie `WIDTH`, Icarus zwykle milczy.
- **`>>>` na wyrażeniu bez znaku** — wsuwa zera, jak `>>`.
- **`$signed(u)` dla liczby bez znaku z ustawionym najstarszym bitem** — zmiana wartości; najpierw `{1'b0, u}`.
- **Stała bez rozmiaru w konkatenacji** — `{a, 1}` to 32-bitowa jedynka; większość narzędzi to odrzuca.

## Pytania rekrutacyjne

1. **Jaki będzie wynik: `wire [3:0] a = 4'd12, b = 4'd5; wire [3:0] s = a + b; wire [4:0] t = a + b;`?**

<details>
<summary>Odpowiedź</summary>

`s` = 1 (17 mod 16), bo wyrażenie liczy się na 4 bitach — szerokości lewej strony i argumentów. `t` = 17, bo lewa strona ma 5 bitów i argumenty są poszerzane przed dodawaniem.
</details>

2. **Jak sprawdzić jedną linijką, czy liczba jest potęgą dwójki?**

<details>
<summary>Odpowiedź</summary>

`(x != 0) && ((x & (x - 1)) == 0)`. Odjęcie 1 zamienia najmłodszą jedynkę na 0 i wszystkie zera pod nią na jedynki; AND z oryginałem zeruje najmłodszą jedynkę. Jeśli wynik jest zerem, jedynka była tylko jedna.
</details>

3. **Kiedy wyrażenie w Verilogu jest liczone ze znakiem?**

<details>
<summary>Odpowiedź</summary>

Tylko gdy wszystkie argumenty są ze znakiem (znak lewej strony przypisania nie ma wpływu). Wystarczy jeden argument bez znaku, wycinek albo konkatenacja i całe wyrażenie jest bez znaku. Liczby bez rozmiaru są ze znakiem, stałe z rozmiarem bez litery `s` — bez znaku.
</details>

## Zadania

1. Przewidź wartości, a potem sprawdź w Icarusie:

```verilog
reg signed [7:0] a = -8'sd8;
reg        [7:0] b = 8'd2;
wire signed [15:0] r1 = a * b;
wire signed [15:0] r2 = a * $signed(b);
wire signed [7:0]  r3 = a >>> 1;
wire        [7:0]  r4 = a >> 1;
```

<details>
<summary>Odpowiedź</summary>

`r1` = 496 (bez znaku: 248 · 2), `r2` = −16, `r3` = −4 (przesunięcie arytmetyczne), `r4` = 124 (logiczne: `0b0111_1100`).
</details>

2. Rozszerz `bit_tricks` o wyjście `msb_index` — numer najstarszej jedynki — i porównaj zapis pętlą z `$clog2`-podobną sztuczką. **Kryterium zaliczenia:** testbench dla wszystkich 255 niezerowych wartości.
