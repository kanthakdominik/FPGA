## Po co to jest

Syntezator to mały system czasu rzeczywistego: protokół z przypadkami brzegowymi (MIDI), arytmetyka stałoprzecinkowa (fazy, obwiednie, skalowanie), współdzielenie zasobów w czasie (jedna mnożarka na cztery głosy) i twardy termin — próbka musi być gotowa co 20,5 µs. Tak samo wyglądają tory audio w produktach, generatory sygnałów i sterowniki silników. Na rozmowie dobrze się o nim opowiada, bo każdy rozumie, co robi, a pytania o szczegóły (running status, kradzież głosu, pomiar częstotliwości w testbenchu) pokazują, czy projekt był naprawdę zrobiony.

## Intuicja

Każdy głos to wskazówka zegara kręcąca się ze stałą prędkością — prędkość wybiera wysokość dźwięku, a kąt wskazówki zamienia się na kształt fali (prostokąt, piła, trójkąt, sinus). Obwiednia ADSR to ręka na suwaku głośności: szybko w górę po naciśnięciu klawisza, trochę w dół, trzyma, a po puszczeniu powoli do zera. Cztery głosy liczone są po kolei przez ten sam „kalkulator”, bo na każdą próbkę mamy 256 taktów, a potrzeba tylko 16.

## Teoria

### MIDI

Bajt z ustawionym bitem 7 to **status**, reszta to dane (0–127). Komunikaty użyte w projekcie:

| Status | Dane | Znaczenie |
|---|---|---|
| `9n` | nuta, prędkość | Note On; prędkość 0 = Note Off |
| `8n` | nuta, prędkość | Note Off |
| `Bn` | 120 / 123, x | wszystkie dźwięki / nuty wyłącz |
| `Cn` | program | kształt fali: program mod 4 |
| `An`, `En` / `Dn` | 2 / 1 bajt | pomijane |

Dwie reguły, które łatwo przeoczyć:

- **running status** — po komunikacie kanałowym kolejne mogą przyjść bez bajtu statusu (klawiatury robią to stale, wysyłając Note On z prędkością 0 zamiast Note Off),
- **komunikaty czasu rzeczywistego** `F8`–`FF` (zegar, start, stop) mogą wejść **w środek** innego komunikatu i nie przerywają go; `F0`–`F7` kasują running status.

Kanał jest ignorowany (tryb omni).

### Głos

- **Faza:** akumulator 24-bitowy, krok `krok_nuty(n)` = `TAB[n mod 12] >> (10 − n div 12)`. Tablica 12 kroków dla najwyższej oktawy (nuty 120–131) daje pozostałe oktawy przesunięciem. Przy fs = 12,5 MHz / 256 = 48 828 Hz: f = krok · fs / 2^24; dla A4 (nuta 69) krok = 151 182 → **440,00 Hz**.
- **Kształt** z faży: prostokąt (bit 23), piła (faza), trójkąt (faza odbita), sinus z tablicy ćwiartki `sin_tab` (moduł 26).
- **ADSR** — 17-bitowa obwiednia, stany CISZA → ATAK → OPAD → PODTRZ → WYBRZ, kroki liniowe w każdej próbce.
- **Wyjście głosu** = fala × obwiednia × prędkość, liczone w 4 taktach jedną mnożarką; suma 4 głosów skalowana do 24 bitów.

### Przydział głosów

Ta sama nuta → ten sam głos (ponowny atak). W przeciwnym razie wolny głos. Gdy wszystkie są zajęte, zabierany jest głos wskazany przez licznik cykliczny (**voice stealing**). Note Off nuty, której głos zabrano, nie może wyłączyć nowej nuty — dlatego Note Off porównuje numer nuty głosu.

### Plan weryfikacji

Testbench wysyła bajty MIDI przez UART (500 kb/s, żeby skrócić symulację; ADSR przyspieszony: A = 8192, D = 1024, S = 0,5, R = 4096 na próbkę), dekoduje I2S z wyjścia i:

- **mierzy częstotliwość** z przejść przez zero przebiegu z portu `probka`,
- sprawdza aktywne głosy po każdej sekwencji (running status z wtrąconym `F8`, Note On z prędkością 0, kradzież głosu, CC 123),
- porównuje każde słowo I2S lewego kanału z próbką syntezatora.

## Schemat i przebiegi

```
 MIDI 31,25 kb/s ─► uart_rx ─► midi_parser ─ ev_on/off, nuta, vel, prog ─► syntezator ─► i2s_master ─► kodek
                                                                              ▲   │ probka 24 b
                       ramka (co 256 taktów) ─────────────────────────────────┘   └─► wskaźnik poziomu (LED)

 jedna próbka (256 taktów przy 12,5 MHz):
  takt: 0..3 głos 0 | 4..7 głos 1 | 8..11 głos 2 | 12..15 głos 3 | suma, skala | ... bezczynność do następnej ramki
        krok 0: ADSR, faza  krok 1: fala  krok 2: fala × obwiednia  krok 3: × prędkość, akumulacja

 "90 5D 64" (Note On 93) · "5D 00" (running status: Note Off) · "F8" w środku komunikatu — pomijane
```

## Kod: VHDL

[hdl/vhdl/syntezator.vhd](hdl/vhdl/syntezator.vhd) — obwiednia ADSR w kroku 0 głosu:

```vhdl
case stan(g) is
  when ATAK =>
    if env(g) + A_KROK >= 65535 then env(g) <= to_unsigned(65535, 17); stan(g) <= OPAD;
    else env(g) <= env(g) + A_KROK; end if;
  when OPAD =>
    if env(g) <= S_POZ + D_KROK then env(g) <= to_unsigned(S_POZ, 17); stan(g) <= PODTRZ;
    else env(g) <= env(g) - D_KROK; end if;
  when WYBRZ =>
    if env(g) <= R_KROK then env(g) <= (others => '0'); stan(g) <= CISZA;
    else env(g) <= env(g) - R_KROK; end if;
  when others => null;                                -- CISZA, PODTRZ: bez zmian
end case;
```

## Kod: Verilog

[hdl/verilog/midi_parser.v](hdl/verilog/midi_parser.v) — running status i komunikaty czasu rzeczywistego:

```verilog
if (dane >= 8'hF8) begin
    // czas rzeczywisty: bez wpływu na komunikat w toku
end else if (dane[7]) begin
    status <= (dane >= 8'hF0) ? 8'd0 : dane;    // F0..F7 kasują running status
    drugi  <= 1'b0;
end else if (status != 8'd0) begin              // bajt danych: status zostaje (running status)
    if (dwa && !drugi) begin d1 <= dane[6:0]; drugi <= 1'b1; end
    else begin
        drugi <= 1'b0;
        case (typ)
            4'h9: begin nuta <= d1; vel <= dane[6:0];
                        if (dane[6:0] != 7'd0) ev_on <= 1'b1; else ev_off <= 1'b1; end
            4'h8: begin nuta <= d1; ev_off <= 1'b1; end
            ...
```

## Co powstaje po syntezie

Yosys (LUT4): `syntezator` — **2399 LUT4, 468 FF**, z czego większość to mnożenie 17 × 17 i 24 × 7 bitów rozłożone na LUT-y oraz tablica `sin_tab` (335 LUT4). Dekoder `midi_parser` to tylko **48 LUT4, 36 FF**, a cały `projekt_syntezator` z UART i I2S — **2667 LUT4, 594 FF**. W Quartusie mnożarka trafia do bloku DSP (MAX 10 ma 18 × 18), a 4 głosy dzielą jeden — to właśnie zysk z liczenia ich po kolei. Takt 12,5 MHz daje 256 taktów na próbkę, z czego potrzeba 16: można mieć **64 głosy** bez dodatkowej mnożarki, gdyby stan głosów trzymać w pamięci M9K zamiast w rejestrach.

## Weryfikacja

`tb_projekt_syntezator` (Icarus, Verilator, GHDL, wyniki jednakowe):

- prostokąt, nuta 93: **1760,45 Hz** (oczekiwane 1760,00 Hz — pomiar z przejść przez zero w skończonym oknie), szczyt +1 040 320 / −1 040 384,
- sinus, nuta 69: **440,00 Hz**,
- aktywne głosy: Note On → `0001`; running status z `F8` w środku → `0111`; prędkość 0 → `0110`; `80` → `0100`; 4 nuty + piąta → `1111` (kradzież); Note Off zabranej nuty → `1111`; CC 123 → `0000`,
- I2S: **6435** słów lewego kanału zgodnych z próbkami, 0 niezgodnych.

## Reguły i liczby do zapamiętania

| Reguła lub liczba | Kiedy obowiązuje |
|-------------------|------------------|
| MIDI: 31 250 b/s, 8N1, bajt statusu ma bit 7 = 1 | każdy interfejs MIDI |
| Running status — dane bez statusu; `F8`–`FF` w środku komunikatu nie przerywają; `F0`–`F7` kasują status | dekodery MIDI |
| Note On z prędkością 0 = Note Off | klawiatury |
| f = krok · fs / 2^N; rozdzielczość fs / 2^N (tu 2,9 mHz) | DDS, NCO |
| Półton: × 2^(1/12) ≈ 1,0595; oktawa: × 2 (przesunięcie) | tablice nut |
| A4 = nuta 69 = 440 Hz | strojenie |
| Współdzielenie w czasie: takty na próbkę / takty na głos = maksymalna liczba głosów | audio, DSP |

## Typowe pułapki

- **Brak running status** — klawiatura gra pierwszą nutę, a kolejne nie działają.
- **`F8` traktowany jak zwykły status** — zegar MIDI z sekwencera przerywa komunikaty i gubi nuty.
- **Note Off po numerze głosu, nie nuty** — po kradzieży głosu puszczenie starego klawisza wyłącza nową nutę.
- **Przepełnienie sumy głosów** — 4 głosy na pełnej skali muszą zmieścić się w zakresie przed skalowaniem; zostaw bity zapasu albo nasycaj.
- **Skokowa zmiana obwiedni** (ATAK = 0 próbek) — trzask w głośniku; nawet najkrótszy atak powinien trwać kilka milisekund.
- **Wejście MIDI bez transoptora** — pętla masy i ryzyko uszkodzenia; specyfikacja wymaga izolacji.

## Pytania rekrutacyjne

1. **Jak obliczysz krok akumulatora fazy dla danej częstotliwości i jak dokładna jest wynikowa częstotliwość?**

<details>
<summary>Odpowiedź</summary>

krok = round(f · 2^N / fs). Przy N = 24 i fs = 48 828 Hz rozdzielczość to fs / 2^N ≈ 2,9 mHz, więc błąd zaokrąglenia kroku jest pomijalny (dla 440 Hz poniżej 0,001 %). W tym projekcie kroki dla oktaw niższych powstają przesunięciem kroku z najwyższej oktawy — to dodatkowo obcina bity, ale przy 24 bitach błąd zostaje w setnych częściach centa. Faktyczna dokładność zależy od oscylatora płytki (np. 50 ppm).
</details>

2. **Co to jest running status w MIDI i jak wpływa na dekoder?**

<details>
<summary>Odpowiedź</summary>

Nadajnik może pominąć bajt statusu, jeśli jest taki sam jak w poprzednim komunikacie kanałowym; odbiornik musi pamiętać ostatni status i traktować bajt danych jako początek nowego komunikatu. Dekoder trzyma więc rejestr statusu, kasuje go przy komunikatach systemowych `F0`–`F7`, nie zmienia przy komunikatach czasu rzeczywistego `F8`–`FF` (te mogą wejść nawet między bajty danych) i liczy bajty danych według typu komunikatu (1 albo 2).
</details>

3. **Masz 4 głosy i jedną mnożarkę. Jak policzysz wszystkie w czasie jednej próbki i ile głosów zmieścisz maksymalnie?**

<details>
<summary>Odpowiedź</summary>

Multipleksuję w czasie: głosy liczone są po kolei, każdy w kilku taktach (tu 4: ADSR i faza, kształt, × obwiednia, × prędkość z akumulacją). Przy 12,5 MHz i fs = 48,8 kHz jest 256 taktów na próbkę, więc teoretycznie 64 głosy po 4 takty. Ograniczeniem staje się wtedy stan głosów (faza, obwiednia, nuta — ok. 60 bitów na głos), który zamiast w rejestrach warto trzymać w pamięci blokowej, oraz zakres sumy.
</details>

## Zadania

1. Dodaj Pitch Bend (`En`, 14 bitów) zmieniający krok wszystkich głosów o ±2 półtony. **Kryterium zaliczenia:** testbench mierzy częstotliwość dla pitch bend 0, +max i −max (z dokładnością 0,5 %), w trzech językach.

2. Zwiększ liczbę głosów do 16, trzymając stan głosów w pamięci (jeden port odczytu, jeden zapisu). **Kryterium zaliczenia:** testbench z 16 nutami naraz i kradzieżą siedemnastej; Yosys pokazuje wzrost FF mniejszy niż 4 ×.

3. Dodaj filtr dolnoprzepustowy (IIR 1. rzędu z 26.02) z częstotliwością odcięcia z CC 74. **Kryterium zaliczenia:** pomiar amplitudy harmonicznej piły w testbenchu przed i po filtrze; odsłuch na DECA.
